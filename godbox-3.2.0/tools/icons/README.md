# GodBox: иконки сил

Собственные пиксельные иконки 16×16 для каждой силы (`Power`) и вкладки (`Category`). Рисуются кодом
(Python + Pillow), палитра ограничена, контур 1 px, свет сверху-слева, фон прозрачный.

## Генерация

    python3 tools/icons/gen.py          # пересобрать атласы + обновить константы в PowerIcons.java
    python3 tools/icons/gen.py --check  # проверить, что атласы и константы соответствуют enum'ам

Выход: `src/main/resources/assets/godbox/textures/gui/power_icons.png` (сетка по 20 ячеек в ряд,
ячейка = `Power.ordinal()`) и `category_icons.png` (одна строка, ячейка = `Category.ordinal()`).
Контактные листы пишутся в `/tmp/verify/sheet_*.png` (иконки ×4 с именами констант).

Скрипт падает, если у константы `Power` нет рецепта, рецепт назван неизвестной константой, иконка
пустая или две иконки совпадают пиксель в пиксель. Хэш порядка констант и их число записываются в
`client/PowerIcons.java`; если enum изменили без перегенерации, `PowerIcons` вернёт `false`
и GUI нарисует предмет.

## Файлы

- `lib.py` — слой с ролями цветов, рампы, контур, мини-шрифт;
- `motifs_a.py … motifs_d.py` — мотивы (бомба, пламя, существа, постройки, сцены биомов, значки 5×5);
- `recipes.py` — таблица `Power -> рецепт` и `Category -> рецепт`;
- `gen.py` — сборка, проверки, атласы, контактные листы.

## Новая сила

1. Добавьте константу в `Power.java`.
2. В `recipes.py` добавьте строку в `POWERS`: `'NEW_POWER': R('мотив', 'рампа', 'рампа2', badge='plus', ...)`.
   Мотив — из `MOTIFS` (или нарисуйте новый: `sprite(...)` из ASCII либо функция с `@motif`),
   значок — из `BADGES` (`plus`, `minus`, `up`, `down`, `x`, `star`, `heart`, `law` и др.).
3. `python3 tools/icons/gen.py`, посмотрите листы в `/tmp/verify/`, закоммитьте PNG и `PowerIcons.java`.

Роли цветов в ASCII-рисунках: `h/m/s` — основная рампа (свет/середина/тень), `H/M/S` — вторая,
остальные буквы — фиксированные цвета (см. `FIXED` в `lib.py`).
